# XO — Mobile multiplayer v3

Play: https://yongvits.github.io/XO/

ใส่ชื่อแล้วเลือกห้องสาธารณะ A, B หรือ C ห้องว่างจะเปิดให้คนแรก คนถัดไปเข้าร่วมโดยตรง ห้องเต็มจะปิดปุ่มเข้าร่วม สถานะและชื่อผู้เล่นตรวจผ่าน WebRTC ทุกประมาณ 12 วินาที มีปุ่มอัปเดตเอง หากตรวจไม่ได้จะแสดงสถานะตรวจไม่สำเร็จ ไม่สรุปว่าห้องว่าง

เว็บไซต์อยู่ใน docs/ เผยแพร่ด้วย GitHub Pages ใช้ PeerJS 1.5.5 จาก unpkg และ PeerJS Cloud เพื่อจับคู่ จากนั้นส่งข้อมูลเกมระหว่างอุปกรณ์ผ่าน WebRTC ต้องมีอินเทอร์เน็ต แนะนำ Wi-Fi เดียวกัน ไม่มี TURN relay ที่ตั้งค่าเฉพาะ บางเครือข่ายอาจเชื่อมต่อไม่ได้

เปิดหน้าเกมค้างไว้ หากปิดหน้า/ล็อกหน้าจอ/หลุด ให้เข้าห้องใหม่ ไม่มีการบันทึกเกม ห้องเหล่านี้ใช้ร่วมกันทุกคน ไม่แยกตาม Wi-Fi ชื่อที่ใส่จะแสดงให้ผู้เข้าหน้าห้องเห็น

server.mjs และ public/ เก็บเวอร์ชัน LAN เดิมไว้
