# เล่นด้วยกัน — XO & หมากฮอสไทย v4

Play: https://yongvits.github.io/XO/

เลือก XO หรือหมากฮอสไทย แล้วใส่ชื่อและเลือกห้อง A / B / C แต่ละเกมมีห้องแยกกัน ห้องว่างจะเปิดให้คนแรก คนถัดไปเข้าร่วมทันที ห้องเต็มจะแสดงชื่อและจำนวน 2/2 สถานะตรวจทุกประมาณ 12 วินาที

หมากฮอสไทย: กระดาน 8×8 ฝ่ายละ 8 ตัว เบี้ยเดินและกินเฉพาะทแยงไปหน้า บังคับกินและกินต่อด้วยตัวเดิม เลือกเส้นทางได้โดยไม่บังคับกินจำนวนมากที่สุด ฮอสเดินทแยงไกลได้ทั้งสี่ทิศ แต่กินแล้วลงช่องติดหลังตัวที่กินทันที นำตัวถูกกินออกทันที ถึงแถวสุดท้ายเข้าฮอสแล้วจบตา ฝ่ายดำเริ่มกระดานแรก และสลับฝ่ายเริ่มกระดานถัดไป หมากหมดหรือเดินไม่ได้คือแพ้ เสมอได้โดยตกลงทั้งสองฝ่าย ไม่มีนาฬิกาแข่งขันหรือการนับ 16 ตาอัตโนมัติ

อ้างอิง: สมาคมกีฬากีฬาไทยแห่งประเทศไทย https://thaisports.org/ประวัติหมากฮอส/ และเอกสารกติกาหมากฮอสไทยที่เชื่อมจากหน้าเดียวกัน

ไฟล์เว็บไซต์อยู่ใน docs/ เผยแพร่ผ่าน GitHub Pages ใช้ PeerJS 1.5.5 จาก unpkg และ PeerJS Cloud สำหรับจับคู่ จากนั้นส่งข้อมูลผ่าน WebRTC เจ้าห้องตรวจทุกตาเดินและผลเกม ต้องมีอินเทอร์เน็ต แนะนำ Wi-Fi เดียวกัน ไม่มี TURN เฉพาะ บางเครือข่ายอาจเชื่อมต่อไม่ได้

เปิดหน้าเกมค้างไว้ หากปิดหน้า/ล็อกหน้าจอ/หลุด ให้เข้าห้องใหม่ ไม่มีการบันทึกเกม ห้องเป็นสาธารณะร่วมกันทุกคนไม่แยกตาม Wi-Fi ชื่อที่ใส่จะแสดงในหน้าห้อง ทั้งสองคนควรรีเฟรชเมื่อมีเวอร์ชันใหม่
