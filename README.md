# OX — Wi-Fi multiplayer

ต้องมี Node.js 20 ขึ้นไปบนคอมพิวเตอร์เครื่องเจ้าห้อง ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

1. เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน `node server.mjs`
2. โปรแกรมจะแสดง `Wi-Fi link: http://192.168.x.x:3000` (เลขแต่ละเครื่องต่างกัน)
3. ให้ทุกคนต่อ Wi-Fi เดียวกัน แล้วเปิดลิงก์นั้นในเบราว์เซอร์
4. ใส่ชื่อและสร้างห้อง อีกเครื่องจะเห็นห้องอัตโนมัติภายในประมาณ 1 วินาที

หากมีหน้าต่างไฟร์วอลล์ ให้อนุญาต Node.js สำหรับเครือข่ายส่วนตัว เครื่องเจ้าห้องต้องเปิดโปรแกรมค้างไว้ หากใช้ Guest Wi-Fi ที่แยกอุปกรณ์ออกจากกัน ให้เปลี่ยนเป็นเครือข่ายที่อนุญาตให้อุปกรณ์เชื่อมต่อกัน

ระบบตรวจตาเดินและผลแพ้ชนะบนเซิร์ฟเวอร์ เล่นใหม่ได้ สลับผู้เริ่มในแต่ละตา ออกจากห้องจะปิดห้องให้ทั้งสองคน ห้องที่ไม่มีการเชื่อมต่อเกิน 30 นาทีจะถูกลบ ข้อมูลเก็บในหน่วยความจำและหายเมื่อปิดโปรแกรม

การค้นหาอัตโนมัติเป็นการค้นหาห้องบนเซิร์ฟเวอร์เดียวกัน ไม่ใช่การสแกนหาเซิร์ฟเวอร์บนเครือข่าย ต้องเปิดลิงก์ครั้งแรกก่อน ไม่จำเป็นต้องมีอินเทอร์เน็ต (ฟอนต์มี system fallback) แอปนี้ออกแบบสำหรับ LAN ที่ไว้ใจกัน ไม่ควรเปิดพอร์ตสู่สาธารณะโดยตรง
