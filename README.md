# XO — mobile multiplayer

เปิด https://yongvits.github.io/XO/ บนมือถือ ไม่ต้องเปิดคอม

1. ใส่ชื่อแล้วกดสร้างห้อง
2. ส่งลิงก์ชวนเพื่อน หรือให้เพื่อนใส่รหัสห้อง 6 ตัว
3. เปิดหน้าเกมค้างไว้ทั้งสองเครื่อง แล้วผลัดกันเล่น X / O

GitHub Pages ให้บริการไฟล์ใน docs/ ใช้ PeerJS 1.5.5 จาก unpkg และ PeerJS Cloud สำหรับ signaling จากนั้นส่งข้อมูลเกมผ่าน WebRTC เจ้าห้องตรวจตาเดินและผลเกม

ต้องใช้อินเทอร์เน็ต ไม่มีระบบค้นหาห้อง Wi-Fi อัตโนมัติ แนะนำ Wi-Fi เดียวกัน เครือข่ายบางแบบอาจบล็อก WebRTC หรือจำเป็นต้องใช้ TURN ซึ่งเวอร์ชันนี้ไม่ได้ตั้งค่า หากหลุด/ปิดหน้า/ล็อกเครื่อง ให้สร้างห้องใหม่ ไม่มีการบันทึกเกม

หาก Actions ไม่สามารถเปิดใช้งาน Pages อัตโนมัติ ให้ตั้ง Settings → Pages → Source → GitHub Actions แล้ว Re-run workflow

server.mjs และ public/ เป็นเวอร์ชัน LAN เดิม ใช้ node server.mjs ได้เช่นเดิม
